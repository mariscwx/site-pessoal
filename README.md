# Site Pessoal

## Sobre o Projeto

Este projeto foi desenvolvido pelos alunos do **1º ano D do Ensino Médio**, para a matéria de **Desenvolvimento**.

O objetivo é apresentar os integrantes do grupo por meio de um site, permitindo que os visitantes conheçam um pouco mais sobre cada pessoa, suas características, interesses e personalidade.

O site é composto por uma página inicial (*Home*) e quatro páginas individuais, cada uma dedicada a um dos integrantes.

## Estrutura do Site

- **Home:** página inicial com a apresentação do projeto e acesso aos perfis dos integrantes.
- **Julie:** página dedicada à apresentação da integrante.
- **Mariana:** página dedicada à apresentação da integrante.
- **Maytê:** página dedicada à apresentação da integrante.
- **Pedro:** página dedicada à apresentação do integrante.
